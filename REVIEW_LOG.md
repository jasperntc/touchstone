# Review log

Mistakes caught while preparing this repository for public release, September–October 2026.

I did the release work with two AI assistants: Claude Code, which made the changes, and Claude in chat, which wrote the step-by-step release plan and reviewed Claude Code's plans before I approved them. Every change went through review. Each row records whose mistake it was, how it was caught, and what changed.

Corrections to the experimental record itself are in [`docs/errata.md`](docs/errata.md), not here.
